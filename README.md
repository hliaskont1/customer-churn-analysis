# Customer Churn Prediction & Statistical Modeling

**Objective:** Predict customer churn using statistical inference and machine learning algorithms.

**Tech Stack:** Python, Scikit-learn, SciPy, Pandas, Matplotlib.

**Methodology:** 
* Conducted Chi-Square and Two-Sample T-Tests to mathematically validate feature significance.
* Cleaned and preprocessed imbalanced data using one-hot encoding and standard scaling.
* Trained and evaluated Logistic Regression and Random Forest Classifiers.

**Key Findings:** 
* Contract type and monthly charges have a statistically significant impact on churn (p < 0.05).
* The Random Forest model identified **Tenure**, **Total Charges**, and **Monthly Charges** as the top three primary drivers of customer attrition.
